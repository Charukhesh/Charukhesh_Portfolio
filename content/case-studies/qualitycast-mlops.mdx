## Overview

QualityCast-MLOps is an industrial grade computer vision platform engineered for real time casting defect detection. Rather than acting as a standalone classification script, it implements a comprehensive Machine Learning Operations (MLOps) lifecycle emphasizing reproducibility, strict versioning, and continuous human feedback loops.

## Technical approach

The platform follows a microservices Clean Architecture deployed entirely locally via Docker Compose. Apache Airflow orchestrates PyTorch training pipelines, while DVC and MLflow handle dataset versioning and experiment tracking. The registered model artifact is served via a high concurrency FastAPI REST endpoint. Factory operators interact through a Streamlit dashboard, submitting visual edge case corrections that are systematically logged to trigger automated retraining pipelines.

## Results

Delivered a fully local, no-cloud reproducible infrastructure with strict Pytest validation schemas and Prometheus/Grafana liveness monitoring for real time edge deployments.
