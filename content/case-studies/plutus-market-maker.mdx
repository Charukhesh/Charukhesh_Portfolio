## Overview

Plutus is an algorithmic market making system developed for the 2026 Akuna Capital Quantitative Trading Challenge. It prices and trades binary event contracts linked to the Fed Funds Rate and private AI company valuations, successfully navigating adversarial simulation stages with continuous bankruptcy constraints.

## Technical approach

The system first infers rate betas and sector volatility via covariance analysis of daily log returns. It uses Monte Carlo simulation with a daily memory cache to achieve millisecond scale stochastic pricing during heavy order flow. Fill-or-Kill (FOK) orders are evaluated against variance limits and a Kelly inspired capital utilization penalty. Request-For-Quote (RFQ) sizing is strictly bounded by available capital, and quotes are skewed based on current inventory using an Avellaneda-Stoikov inspired model to enforce continuous rebalancing.

## Results

The system survived all 20 adversarial simulation stages without breaching bankruptcy constraints while keeping capital utilization strictly below the 85% limit.
