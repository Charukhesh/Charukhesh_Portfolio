## Overview

This project introduces a hybrid system identification framework combining Sparse Identification of Nonlinear Dynamics (SINDy) and Recursive Least Squares (RLS). It successfully isolates physical plant dynamics from active controller behavior in tightly coupled closed-loop systems, solving the persistent "Ghost Controller" problem in data driven discovery.

## Technical approach

The system uses an inverted pendulum on a cart controlled by LQR. First, implicit SINDy with two-pass Sequential Threshold Ridge Regression is applied to rich open-loop excitation data to discover the sparse structural forms of the inertial equations. Next, the closed-loop force balance is reformulated mathematically. RLS is deployed on the closed-loop data to simultaneously estimate the hidden LQR gains and the true physical cart friction, decoupling the software policy from the hardware physics.

## Results

Controller gains converged to true values within seconds with under 4% identification error. The resulting physical model successfully predicted uncontrolled chaotic pendulum motion rather than reproducing ghost controller artifacts.
