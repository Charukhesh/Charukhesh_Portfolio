## Overview

Long-horizon manipulation instructions ("clear the counter and load the dishwasher") require grounding language in
*structure*, not just objects, what's on top of what, what's reachable, what depends on what. This project builds
hierarchical 3D scene graphs from ground-truth depth scans and uses them as the grounding layer an LLM planner
reasons over.

## Technical approach

Ground-truth depth scans are converted into hierarchical, semantically labeled 3D scene graphs (containment,
support and spatial-adjacency relations between objects and surfaces). Natural-language instructions are
decomposed by the LLM planner into sub-goals grounded against nodes in this graph, converting the MobiPi framework
to operate over graph-structured state rather than flat object lists, and executed step-by-step inside RoboCasa.

## Results

Produced spatially consistent multi-step action plans from natural-language instructions, executed autonomously in
the RoboCasa simulator.

## Industrial application

| | |
|---|---|
| **Industry** | Home/service robotics, warehouse automation, logistics |
| **Problem** | Executing long-horizon, language-specified tasks that require spatial and relational reasoning beyond single-step pick/place |
| **How it helps** | Structured scene graphs give the planner explicit relational grounding, reducing ambiguity in what "clear the counter" or "load the dishwasher" concretely requires |
| **Deployment path** | RoboCasa simulation → real depth-sensor pipeline → physical robot deployment (future stages) |
